Installation

You can use BlobAnim in several ways:

1. Via npm

npm install blob-anim

2. Direct download

Download the library file and include it in your project. Note that you need to include D3.js as well:

<script src="https://d3js.org/d3.v7.min.js"></script> <script type=\"module\" src=\"blob-anim.es.js\"></script>

Configuration Options

Option Type Default Description
count Number 5 Number of blobs to display
size Number 20 Size of each blob
colors Array null Array of colors to use for blobs (overrides single color)
opacity Number 1 Opacity of the blobs (0-1)
speed Number 1 Animation speed (higher = faster)
state String 'chaos' Animation state: 'chaos', 'organizing', 'structured'
variant String 'default' Animation variant within each state
gooey Boolean true Enable gooey effect
scaleEffects Boolean true Enable scaling effects during animation
width Number Container width Width of the animation container (px)
height Number Container height Height of the animation container (px)
colorMode String 'random' How to use colors from colorList: 'random', 'sequence', or 'gradient'
gradient Boolean false Enable radial gradient fill effect for blobs
glass Boolean false Enable glass effect for blobs
glassBlobs Array [] Array of blob indices to apply glass effect to
chaosAmount Number 1 Amount of chaos/randomness in animations (0-1)

Animation States and Variants

The library includes several pre-defined animation states and variants:

State Variants
chaos default, random, spiral, explosion, brownian, math-explosion, math, circle
organizing default, grid, spiral, wave, cylinder
structured default, grid, circle, orbit, flower, basic

JavaScript API

The library provides several methods for controlling the animation:

// Create an animation const animation = createAnim(container, options); // Update configuration animation.update({ count: 5, colors: ['#10b981'] }); // Pause animation animation.pause(); // Resume animation animation.resume(); // Resize the animation (for web component only) blobAnimElement.resize(400, 300); // Get performance metrics const metrics = animation.getPerformanceMetrics(); console.log(`Current FPS: ${metrics.fps}`); // Clean up resources animation.destroy();

Advanced Usage and Customization

BlobAnim supports advanced customization through the JavaScript API. You can define custom animation patterns by extending the library's functionality:

// Define a custom animation pattern function customPattern(d, i, t, count, w, h) { const centerX = w / 2; const centerY = h / 2; const angle = (i / count) * Math.PI * 2 + t; const radius = w * 0.3 + Math.sin(t * 3 + i) * w * 0.05; return { x: centerX + Math.cos(angle) * radius, y: centerY + Math.sin(angle) * radius }; } // Apply the custom pattern (Note: This requires direct API access) const animation = createAnim(container, { count: 5, colors: ['#10b981'], gooey: true }); // Currently, custom patterns require modifying the library or using a wrapper // Future updates may provide direct pattern injection

Using RGBA Colors

BlobAnim supports RGBA colors for creating semi-transparent or gradient-like effects. You can use RGBA colors in two ways:

// Method 1: Use RGBA color string (transparency included in color) <blob-element color="rgba(59, 130, 246, 0.5)" count="15" ></blob-element> // Method 2: Use hex/rgb color with separate opacity setting <blob-element color="#3b82f6" opacity="0.5" count="15" ></blob-element>

When using RGBA colors, if you don't specify an opacity attribute, the alpha channel from the RGBA color will be used automatically. If both are specified, the opacity attribute will take precedence.

Using Multiple Colors

BlobAnim supports using multiple colors for blobs. You can provide an array of colors and specify how they should be applied:

// Using multiple colors with the Web Component <blob-element colorlist='["#3b82f6", "#10b981", "#f59e0b", "#ef4444"]' colormode="random" ></blob-element> // Using multiple colors with the JavaScript API const animation = createAnim(container, { colors: ['#3b82f6', '#10b981', '#f59e0b', '#ef4444'], colorMode: 'sequence' });

There are three color modes available:

  • random - Each blob gets a randomly selected color from the list
  • sequence - Colors are applied in sequence to blobs in order
  • gradient - Colors are distributed evenly based on position
