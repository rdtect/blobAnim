Basic Usage

The BlobAnim library can be used easily in any project with D3.js as a dependency.

1. Load the scripts

<script src="https://d3js.org/d3.v7.min.js"></script> <script type=\"module\" src=\"blob-anim.es.js\"></script>

2. Use as a Web Component

<blob-element count="5" colors='["#3b82f6"]' state="chaos" variant="spiral" gooey ></blob-element>

3. Or use the JavaScript API

const container = document.getElementById('animation-container'); const animation = createAnim(container, { count: 5, colors: ['#10b981'], state: 'organizing', variant: 'wave', gooey: true, width: 350, height: 350 }); // Control methods animation.pause(); animation.resume(); // Update configuration animation.update({ count: 5, colors: ['#10b981'] }); // Clean up resources animation.destroy();
