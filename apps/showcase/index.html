Usage Examples

HTML
JavaScript
<!-- Import the web component -->
<script type="module" src="blob-anim/web-component"></script>

<!-- Use it in your HTML -->
<blob-anim
  count="3"
  size="40"
  speed="1.5"
  state="chaos"
  variant="default"
  color="#3b82f6"
  gooey
></blob-anim>
// Get reference to the element
const blob = document.getElementById('myBlob');

// Update multiple properties at once
blob.update({
  count: 30,
  size: 10,
  color: "#10b981",
  state: "organizing",
  speed: 1.5,
  gooey: false
});

// Control methods
blob.pause();   // Pause animation
blob.resume();  // Resume animation
blob.resize(300, 300); // Resize container and animation
blob.destroy(); // Clean up resources

Configuration Options

Option Type Default Description
count Number 10 Number of blobs to display
size Number 20 Size of each blob
color String #3b82f6 Color of the blobs
speed Number 1 Animation speed
state String chaos Animation state (chaos, organizing, structured)
gooey Boolean true Enable gooey effect
scaleeffects Boolean true Enable scaling animations
